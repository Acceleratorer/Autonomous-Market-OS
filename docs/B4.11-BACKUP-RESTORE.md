# B4.11 Backup and Restore

**Status:** Implemented locally on 2026-10-28 as a synthetic, paper-only operational slice.

## Scope

- Create an opt-in local ZIP backup for one portfolio.
- Include only immutable genesis, policy, ledger, and checkpoint files.
- Record file sizes and SHA-256 fingerprints in a versioned manifest.
- Restore into a new portfolio directory after validating archive paths, schema, fingerprints, and broker recovery.
- Refuse to overwrite an existing portfolio and refuse archives placed inside the source portfolio.

The backup is a copy operation. It does not delete, truncate, rewrite, or retain-delete source ledger records.

## Public seams and evidence

The public seams are `backup_portfolio()` and `restore_portfolio()` in `market_os.portfolio_backup`. Regression coverage is in `market_os/tests/test_portfolio_backup.py`.

## Boundaries

B4.11 does not add partial fills, expiry, shared portfolios, distributed concurrency, mutation API routes, provider access, live data, trading, deployment, or remote backup storage. Retention remains indefinite and local by policy. Version migration remains a separate gate; unsupported backup schema versions fail closed.

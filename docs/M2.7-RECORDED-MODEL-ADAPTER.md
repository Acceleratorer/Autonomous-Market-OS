# M2.7: Recorded-response model adapter

Status: implemented offline; M2.8 live smoke preparation complete; live smoke not run.

## Boundary

`market_os.adapters.openai_summary` implements the existing
`SummaryModelProvider` seam. It has no third-party SDK dependency and is not
imported by the default workflow. It returns `ModelOutput`; `gate_summary`
remains authoritative for citation resolution, exact quote grounding,
provenance, hashes, lineage, output limits, secret-like text, and deterministic
fallback.

Selections are explicit and require the cited LightRAG workflow:

- `deterministic-test`: existing local deterministic provider;
- `openai-recorded`: synthetic recorded Responses-shaped fixture mode;
- `openai`: live OpenAI Responses mode, approval-gated and disabled by default.

## Recorded responses

`market_os/tests/fixtures/model_summary/openai_responses.json` is synthetic
internal data only. It covers supported, inference, unsupported, missing and
invalid citations, quote mismatch, cross-run references, malformed output,
provider error, timeout, excessive output, secret-like output,
prompt-injection-like output, and missing usage. Tests do not call a provider
and do not establish real model quality.

## Live configuration and fail-closed gate

The live provider requires all these environment values:

```text
OPENAI_API_KEY
MARKET_OS_OPENAI_LIVE_APPROVED=1
MARKET_OS_OPENAI_MODEL=gpt-6.1-sol
MARKET_OS_OPENAI_MAX_REQUESTS=1..2
MARKET_OS_OPENAI_MAX_OUTPUT_TOKENS=1..512
MARKET_OS_OPENAI_MAX_INPUT_BYTES=1..16000
MARKET_OS_OPENAI_MAX_SPEND_USD>0
MARKET_OS_OPENAI_REQUEST_TIMEOUT_SECONDS=0..30
MARKET_OS_OPENAI_MAX_RETRIES=0..1
MARKET_OS_OPENAI_DATA_RETENTION_ACK=1
MARKET_OS_NON_PRODUCTION=1
MARKET_OS_PAPER_ONLY=1
```

Missing or invalid settings fail before HTTP transport. A logical operation is
limited to one request and at most two transport attempts, with at most one
retry for transient 408/429/5xx/transport errors. It is bounded by 30 seconds,
512 output tokens, 16 KB serialized input, and a configured spend ceiling. The request sets `store: false`, enables no tools, and sends only the
objective plus normalized cited synthesis. It does not send local filesystem
paths, environment variables, or broker state. The adapter does not log or
persist raw response text or the authorization value.

The spend ceiling is cumulative for a provider instance: each logical request
reserves its worst-case bounded attempt cost before transport, including its
configured retry allowance. A later request is rejected before transport when
that reservation would exceed the ceiling. Provider-reported usage remains
observational and unknown usage stays `None`.

Provider usage is retained only when returned. Unknown input/output counts and
cost remain `None`, never zero; when both counts are returned, cost is derived
from the documented standard Sol rates of $2.00 per million input tokens and
$10.00 per million output tokens. The adapter does not request regional
processing; any future regional pricing option must update both the reservation
and reporting basis before use. The existing citation gate controls whether
model output can be published. It cannot change paper-only policy, orders, or
risk decisions.

## Official provider status

Official OpenAI documentation reviewed 2026-10-16 confirms model ID
`gpt-6.1-sol`, `/v1/responses` support, Structured Outputs for the Responses
API, and US/EU data-residency support. Account entitlement, credential access,
retention approval, and a live destination approval were not assumed. No SDK
was installed and no live smoke was run.

M2.8 offline preparation records a single synthetic request fingerprint and
keeps the live call pending separate approval. See
[`docs/M2.8-LIVE-SMOKE.md`](M2.8-LIVE-SMOKE.md).

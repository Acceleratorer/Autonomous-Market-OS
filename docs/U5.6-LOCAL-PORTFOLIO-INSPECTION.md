# U5.6 Local Portfolio Inspection

**Status:** Implemented locally on 2026-10-29.  
**Scope:** Read-only browser inspection of the synthetic shared-portfolio
contract.

## Contract

The loopback route `/operator/` lists validated local portfolios, and
`/operator/<portfolio-id>/` reads the existing GET-only
B4 resources in parallel:

- `summary` for balances, mark price, event count, and open orders;
- `genesis` for stable portfolio identity, fixture lineage, policy fingerprint,
  and shared strategy membership;
- `reservations` for portfolio-wide cash and inventory reservations;
- `orders` for strategy-attributed order state;
- `risk` for append-only rejection and risk audit outcomes.

The matching JSON catalog is `GET /v1/b4/portfolios`. Invalid or unreadable
portfolio directories are omitted from the catalog rather than exposed as
unvalidated browser links.

The browser renders these records as text or table cells. It does not calculate
portfolio state, infer authorization, or send mutation requests. The Python
broker remains the source of truth for accounting, membership, reservations,
ordering, recovery, and fingerprints.

## Boundary

- synthetic, paper-only, local, and GET-only;
- no credential, session, provider, live venue, or public listener;
- no query parameters or user-controlled asset paths;
- no framework or package manager added;
- stale or invalid broker state continues to fail through the existing API
  recovery path.

The static preview under `apps/web/public` remains disconnected. This slice is
the local operator shell only.

The existing application-surface, U5 acceptance, static artifact, compile,

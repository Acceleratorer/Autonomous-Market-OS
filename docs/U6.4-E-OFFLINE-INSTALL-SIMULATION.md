# U6.4-E Offline Install Simulation

## Scope

U6.4-E simulates installing one signed U6.4-C target-native artifact into a
new destination without registering a service, embedding Python, changing
release slots, or changing the execution boundary.

The simulation:

- verifies the source artifact and its signature with the U6.4-D preflight;
- copies through a sibling staging directory and publishes with one rename;
- excludes mutable `python/.market_os` state and creates a fresh empty storage
  root in the destination;
- rechecks the staged and published artifact, manifest/signature, full artifact
  tree digest, required entrypoints, slot metadata, and safety boundary;
- rejects nested or existing destinations and unsigned artifacts by default;
- removes staging or the published destination if post-copy verification fails.

The output schema is `market-os.u6.4-install-simulation@v1`.

## Reproducible command

```text
cd apps/desktop/electron
pnpm run install:simulate -- \
  --artifact ../../../output/u6.4-ci/windows-x64/artifact-candidate \
  --destination ../../../output/u6.4-ci/windows-x64/installed-candidate \
  --json ../../../output/u6.4-ci/windows-x64/install-simulation.json \
  --markdown ../../../output/u6.4-ci/windows-x64/install-simulation.md
```

The command requires a signed artifact by default. `--allow-unsigned` exists
only for local fixture inspection and is not used by CI.

CI runs the simulation on both matching Windows/Linux U6.4-C runners after the
U6.4-D preflight and uploads the JSON/Markdown evidence.

## Explicit non-goals

- no MSI, AppImage, native service, or OS package installation;
- no embedded Python runtime;
- no credentials, providers, public listener, mutation route, or live
  execution; and
- no U5.5 VM, systemd, or Tailscale promotion.

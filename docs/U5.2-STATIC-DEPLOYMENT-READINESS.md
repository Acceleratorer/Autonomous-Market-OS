# U5.2 Static Deployment Readiness

**Status:** Ready for a separately approved static artifact handoff on 2026-10-28.
**Scope:** Synthetic, paper-only, read-only web preview packaging.

## Contract

The canonical source is `apps/web/public/`. A valid artifact contains exactly
`index.html`, `.htaccess`, and `DEPLOYMENT.txt`; every byte must match the
canonical source and the retained compatibility copy under
`docs/hosting/market-os/`.

The packaging check rejects scripts, forms, browser network APIs, external URL
markers, credential markers, extra files, and non-empty output directories.
Packaging is deterministic and does not connect to the local API, portfolio
store, providers, or a deployment service.

## Verification

- `python scripts/build_web_artifact.py --check` validates source parity and
  the static boundary.
- `market_os/tests/test_app_surfaces.py` packages the artifact twice and checks
  exact file-set and byte parity.
- The Node contract test checks the read-only/no-script/no-credential surface.
- Playwright browser review at desktop and 375px mobile found no console errors,
  no horizontal overflow, and one document request only.

## Remaining gate

This readiness result authorizes preparation of a static artifact only. It does
not authorize public deployment, authentication, shared access, connected API
calls, mutation routes, credentials, or live trading. A deployment target and
access policy require a separate versioned decision.

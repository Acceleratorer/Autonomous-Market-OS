# U5.7 Web Stack and Deployment Matrix

**Status:** Decision matrix recorded on 2026-10-29; local framework choice
superseded by U5.8.  
**Scope:** Selecting the next web implementation and deployment boundary while
keeping the current product synthetic, local, paper-only, and read-only.

## Current evidence

The repository has a deterministic Python domain/API, a disconnected static
preview, and a loopback operator shell that now inspects shared membership,
reservations, orders, and risk audit outcomes. The browser has no client-owned
accounting or mutation logic.

## Stack matrix

| Candidate | Use when | Immediate work | Gate |
|---|---|---|---|
| Plain HTML/CSS/JS | Static preview and compatibility shell | Keep the existing artifacts available | Active for those surfaces |
| Astro | Multiple read-only routes need shared components and small islands | Define component boundaries and static build contract | First framework candidate |
| React + Vite | Client-side filters, comparisons, and richer state become real | Define client state and bundle budget | Requires approved interaction scope |
| Next.js local | Local server-rendered portfolio inspection is selected | Use a loopback Node runtime and existing Python GET API | Selected in U5.8 |
| Next.js connected | Server-rendered authenticated web is required | Define server runtime, secret boundary, sessions, and observability | Selected for private preview by ADR-0045; host/auth remain gated |

## Deployment matrix

| Target | Fits | Required evidence before use | Current status |
|---|---|---|---|
| Local loopback | Deterministic operator review | Existing U5.1–U5.6 tests | Active |
| Static artifact handoff | Disconnected preview | U5.2 manifest/parity checks | Ready locally |
| Private authenticated preview | Single-tenant read-only inspection | Verified identity propagation, subject/portfolio allowlists, session and denied-request matrix | Scope and stack selected; host and login remain open |
| Public connected deployment | Externally reachable browser app | Provider/runtime, secrets, rate limits, rollback, audit, backup, incident controls | Not enabled |

## Selection rule

U5.8 selected Next.js for the local operator, and ADR-0045 selects the same
stack for the private single-tenant preview. Neither choice selects a host or
access service. Astro remains a componentized read-only candidate, React + Vite
remains a candidate for approved client-side interaction, and connected use
still requires the U5.5 identity, runtime, and operations inputs.

## Required decision inputs

1. Deployment target and network exposure.
2. Identity provider or access-service login method.
3. Tenant and portfolio storage isolation model.
4. Session expiry, revocation, and audit requirements.
5. Read-only interaction scope and browser support matrix.

No credentials, provider, public listener, mutation route, or live trading path
is introduced by this matrix.

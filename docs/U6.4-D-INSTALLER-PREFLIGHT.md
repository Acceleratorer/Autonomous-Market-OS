# U6.4-D Installer Preflight

**Status:** Implemented and verified locally and in CI as an offline artifact
preflight. It does not install a service, embed Python, change release slots,
or promote a connected runtime.

## Contract

The preflight consumes one unpacked U6.4-C target-native artifact and emits
`market-os.u6.4-install-preflight@v1`. It fails closed unless all of the
following hold:

- the artifact manifest and digest are valid;
- the target is `windows-x64` or `linux-x64` and matches the runner;
- the signed release verifies when `--require-signed` is supplied;
- the target-native Electron binary and the shell, Next.js, gateway, and
  Python dependency entrypoints exist under the artifact root;
- the Python sidecar remains a source package under `python/` and requires
  Python `>=3.11`;
- storage remains `python/.market_os` with `artifact-local` scope and no shared
  host root;
- current and known-good slot metadata are present; and
- the private, synthetic, read-only, paper-only, loopback-only,
  execution-disabled boundary is unchanged.

An optional destination is checked only for separation from the source
artifact. The command never creates the destination or changes any artifact
state.

## Reproducible command

```text
cd apps/desktop/electron
pnpm run install:preflight -- \
  --artifact ../../../output/u6.4-ci/windows-x64/artifact-candidate \
  --target windows-x64 \
  --require-signed \
  --json ../../../output/u6.4-ci/windows-x64/install-preflight.json \
  --markdown ../../../output/u6.4-ci/windows-x64/install-preflight.md
```

CI runs the same check after U6.4-C evidence validation on both matching
Windows/Linux runners and uploads the JSON/Markdown output with the release
evidence.

## Explicit non-goals

- no embedded Python runtime;
- no MSI, AppImage, service registration, or OS package installation;
- no credentials, providers, public listener, mutation route, or live
  execution; and
- no U5.5 VM or Tailscale promotion.

# ADR-0054: U6.4 unsigned desktop packaging contract\n\n**Status:** accepted; U6.4-A, U6.4-B, and U6.4-C local release contract verified\n**Date:** 2026-11-06\n\n## Context\n\nU6.3 verified the Electron lifecycle and renderer security boundary, but the\nshell still started from the repository working tree. U6.4 needs a reproducible\nartifact that can be copied to a clean directory while preserving the existing\nNext.js renderer and Python authority.\n\n## Decision\n\nThe first U6.4 slice produces a directory artifact for one target at a time:\n\n```text\nartifact/\n├── artifact-manifest.json\n├── artifact-manifest.json.sha256\n├── slots/current.json\n├── slots/known-good.json\n├── shell/       # Electron source, package metadata, and runtime dependencies\n├── web/         # Next.js production output and runtime dependencies\n└── python/      # market_os + apps/gateway source sidecar and pyproject.toml\n```\n\nSupported target labels are `windows-x64` and `linux-x64`. The artifact keeps\nElectron and Next entrypoints as direct paths so pnpm's platform-specific shim\nfiles, which can contain build-machine paths on Windows, are never used at\nruntime.\n\nThe Python sidecar is source-bundled in U6.4-A and U6.4-C. Each matching CI\nrunner records its native `python` or `python3` interpreter and keeps the\ndefault state root at `python/.market_os`. It runs with system Python 3.11+ and\nthe dependencies declared in `pyproject.toml`. Embedding a platform-specific\nPython distribution remains a later packaging choice; the sidecar remains the\nonly accounting, persistence, recovery, and inspection authority.\n\nThe manifest records:\n\n- artifact schema, version, target, platform, and runtime requirements;\n- web/Electron pnpm lockfile fingerprints;\n- component tree hashes for shell, renderer, and Python sidecar;\n- direct entrypoints and Python dependency declarations;\n- artifact-local Python storage root (`python/.market_os`) with no shared host root;\n- unsigned signature state and current/known-good slot metadata;\n- loopback, synthetic, paper-only, read-only, and mutation-disabled boundary.\n\n## Verification contract\n\n`pnpm run package:unsigned` requires a successful Next.js production build and\ncreates the artifact. `pnpm run smoke:artifact -- --artifact <dir>` starts the\nartifact from its own directory, verifies `/readyz`, `/healthz`, `/overview`,\nand `/runtime`, checks the unsigned release state, and confirms both loopback\nports close after shutdown.\n\n## U6.4-B release contract\n\nU6.4-B keeps the artifact manifest immutable and stores the signature beside it\nin `release-signature.json`. An external Ed25519 private key signs the exact\nmanifest bytes. The artifact contains only the public key, signature bytes,\nkey fingerprint, and signed manifest SHA-256; no private key is accepted from\ninside the artifact directory. `verifyArtifact` checks both the manifest\nsidecar hash and the signature before a release can be promoted.\n\nPromotion writes `slots/current.json` and retains the previous current record as\n`slots/known-good.json`. Each slot records its artifact root and manifest hash.\nThe launch-failure simulation restores both records before returning an error.\nRollback verifies the known-good artifact and hash again before changing the\ncurrent slot, so a tampered or incomplete release leaves the current metadata\nunchanged.\n\n`LocalRuntime` and `/runtime` read the slot and signature metadata when it is\npresent. The UI reports signed/current/known-good/rollback state, but remains\nobservational; it does not promote a release, open connected access, or enable\nexecution. The source Python sidecar remains the accounting, persistence,\nrecovery, and inspection authority.\n\nFocused Electron tests and the CI `u6-4-release-contract` job cover external\nkey signing, signature verification, failed-launch restoration, successful\npromotion, rollback, and tamper rejection. No signing key, credential,\nprovider, mutation route, public listener, or live-trading path is introduced\nby this decision. Platform-specific Python distribution and owner-VM U5.5\npromotion remain deferred.\n

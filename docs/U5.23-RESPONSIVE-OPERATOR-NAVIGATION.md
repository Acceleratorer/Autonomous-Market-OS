# U5.23 Responsive Operator Navigation

**Status:** Implemented and verified locally on 2026-10-29.
**Scope:** Responsive layout and keyboard navigation for the local Next.js operator shell.

## Contract

- Keep primary navigation in source order. At widths below 900px it may wrap;
  at widths up to 560px use a two-column grid with links at least 44px high.
- Avoid page-level horizontal scrolling at 320, 375, 768, 1024, and 1440 CSS
  pixels. Wide data tables may scroll within their labelled region.
- Keep the skip link first in keyboard order and move focus to the main content
  after activation.
- Show a visible keyboard focus indicator on keyboard-focusable table-scroll
  regions.
- Keep the shell server-rendered, local-only, GET-only, paper-only, and
  read-only. No new runtime dependency or animation is introduced.

## Implementation

The root no longer forces a 320px minimum width, which had caused a 15px
horizontal overflow at a 320px browser viewport when a classic scrollbar
reduced the layout width. The skip-link target is programmatically focusable;
scrollable table regions share the existing accent focus outline used by links
and buttons. Existing navigation breakpoints and 44px targets remain intact.

## Verification

- Next.js typecheck and optimized production build passed.
- Playwright checked `/overview`, `/`, `/datasets`, and `/experiments` at 320,
  375, 768, 1024, and 1440 CSS pixels. No page-level horizontal overflow was
  observed; the four primary links remained at least 44px high and each page
  retained one main `h1`.
- Keyboard check: first Tab focused “Skip to content”; Enter focused
  `main#main-content` with `tabIndex=-1`.
- A temporary keyboard-focusable element using the shared `table-scroll` class
  confirmed a visible 2px accent outline; the temporary element was removed.
- The configured local API was unavailable, so catalog pages rendered their
  existing unavailable states. This pass did not exercise populated detail
  tables or backend data.
- The 320px overview screenshot is in `output/playwright/u5-23/`.

Machine-readable results are in
`docs/evidence/u5-23-responsive-operator-navigation.json`.

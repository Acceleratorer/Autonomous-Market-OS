# U5.21 Bounded BTC Candle Visualization

**Status:** Implemented locally on 2026-10-29.

**Scope:** Add a static candlestick visualization to the existing bounded BTC dataset detail page.

## Contract

- The chart renders only the current server-loaded candle page, which is capped at 100 rows by U5.16. An empty cursor page has no chart.
- Chart geometry is derived from the already validated open, high, low, and close strings. The exact original OHLC and volume strings remain in the table below it.
- The visible page high and low use their exact stored strings. The page time range, candle count, quote unit (USDT), and bounded-page scope are stated alongside the chart.
- Rising candles use a filled body; falling candles use a hollow body and dashed wick; flat candles use a neutral outline. The legend names each encoding so direction is not conveyed by color alone.
- Page extrema and candle direction compare the validated decimal strings exactly. `Number` conversion is used only for approximate SVG geometry.
- The chart is a server-rendered inline SVG. It adds no client state, route, data request, chart dependency, provider call, or ingestion action.
- The detail page remains read-only and motion-free. The existing hash verification and canonical replay requirements are unchanged.

## Design

The page-specific design contract now includes a static chart for the current bounded page. It uses the existing dark palette, quiet grid lines, visible time labels, exact page extrema, and an accessible SVG title and description. The exact-value table remains the reference for precise inspection and narrow-screen horizontal scrolling.

No animation candidate passed the motion gate: the chart communicates stored market data, and moving the candles or revealing the chart would not improve inspection.

## Verification

- Next.js typecheck and production build passed.
- Production browser smoke passed at 320, 375, 768, 1024, and 1440 px. It verified the rising, falling, and flat encodings, the exact-value table, the valid empty cursor page, reduced motion, no page overflow, 49 local browser requests, and zero browser-console errors.
- Desktop and mobile screenshots were visually reviewed. Standards, spec, and security reviews found no actionable issues.
- Machine-readable results are recorded in `docs/evidence/u5-21-bounded-btc-candle-visualization.json`.

## Remaining limits

- The chart shows only the requested page, not the complete dataset range.
- Numeric plot geometry uses JavaScript numbers for display; exact stored decimal strings remain available in the table.
- Per-page Parquet hashing, canonical replay, and the U5.5 connected-deployment decisions remain unchanged.

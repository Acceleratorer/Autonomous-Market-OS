# U5.4 Local Operator Shell

**Status:** Implemented locally on 2026-10-29.
**Scope:** GET-only browser shell over the loopback B4 inspection contract.

## Contract

`/operator/<portfolio-id>/` serves a small browser operator shell from
`apps/web/operator/`. It fetches only
`GET /v1/b4/portfolios/<portfolio-id>/summary`, renders balances, mark price,
event count, and open-order count, and links to the existing read-only server
dashboard and health endpoint.

The shell has no submit, cancel, approval, provider, credential, or live venue
path. The canonical asset requests are `index.html`, `operator.js`, and
`operator.css`; `app.js` and `styles.css` remain read-only compatibility aliases
for existing local bookmarks and tests. The route rejects query parameters,
traversal, and private files while retaining the loopback Host boundary. Browser
requests explicitly omit credentials, and the asset response applies CSP,
`nosniff`, and `no-referrer` headers. The public
static artifact under `apps/web/public` remains script-free and disconnected;
this connected shell is local-only.

## Verification

- Summary inspection exposes the stable `open_orders` count used by the shell.
- Route tests cover HTML/JS/CSS content types, summary parity, query rejection,
  POST rejection, and private asset rejection.
- Browser smoke covers desktop/mobile rendering, the summary fetch, no console
  errors, and no mutation controls.

## Remaining gate

Authentication, shared access, public deployment, retention, migration
transformation, and mutation routes remain separate contracts.

# U5.20 Local Operator Overview

**Status:** Implemented locally on 2026-10-29.  
**Scope:** Add a single read-only entry page across the existing local portfolio, BTC dataset, and offline research surfaces.

## Contract

- `/overview` is a server-rendered Next.js page using the configured loopback gateway and the existing validated catalog clients.
- It reads at most three portfolio records, three BTC datasets, and three records from each B2/B3 catalog. Summaries describe only the records shown; they do not imply whole-catalog totals.
- Each catalog is fetched independently. An unavailable or invalid resource shows its own service state without hiding successfully loaded sections.
- Links lead to existing portfolio, dataset, and experiment pages. The portfolio registry remains available at `/`.
- The overview exposes no API roots, filesystem paths, raw payloads, mutation controls, market-provider calls, or derived performance metrics.
- Gateway status and the recovery instruction use the configured local API port.
- B3 summaries retain the `not-promoted` boundary. The page does not present B1 fixture rows as evidence of predictive performance.

## Design

The home uses the existing dark, dense dashboard tokens and server components. It shows a compact first-page count row, then three resource panels with validated records and direct navigation. The local, read-only, synthetic/paper boundary remains visible. Links have visible focus and hover states, touch-sized rows, and mobile layouts; no new motion or client-side JavaScript is introduced.

## Verification

- Next.js typecheck and optimized production build passed.
- Browser smoke covered populated summaries, navigation to a BTC dataset detail and the BTC research catalog, and page widths of 375, 768, 1024, and 1440 px. It verified the skip link, 44 px interactive targets, and reduced-motion behavior. The document had no horizontal overflow, all 32 browser requests stayed on the local Next.js operator, and the browser console had no errors.
- The unavailable-gateway state was checked independently and displayed the configured port without a page error.
- Standards and spec reviews found no residual issues after fixes; security review found no actionable issues.
- Screenshots are in `output/playwright/u5-20/screenshots/`.

## Remaining limits

- The shipped B1 fixture has no leakage-safe test labels, so B2/B3 metrics remain unavailable.
- Connected deployment remains gated by the U5.5 target, identity, isolation, and operations decisions. The local TypeScript/React/Node.js/Next.js/Tailwind stack remains selected and in use.
- The next product surface should be selected after this overview slice.

# B4.6 Malformed Persisted Metadata

**Status:** Implemented locally on 2026-10-27 as a synthetic, paper-only hardening slice.

**Purpose:** Make recovery fail closed with stable broker errors when persisted portfolio metadata is undecodable or has the wrong JSON shape.

## Scope

- Normalize malformed `genesis.json` and `policy.json` reads to `BrokerRejected("genesis is malformed")` or `BrokerRejected("policy is malformed")`.
- Normalize malformed `checkpoint.json` reads to `BrokerRejected("checkpoint is malformed")`.
- Reject non-object JSON metadata before schema or identity validation.
- Reuse the same guarded metadata reader from `B41Broker.__init__()`, `B41Broker.open()`, and `B41Broker.recover()`.

## Public seam and evidence

The public seams are `B41Broker.open()` and `B41Broker.recover()`. Regression coverage is in [test_portfolio_broker.py](../market_os/tests/test_portfolio_broker.py), covering malformed genesis, policy, and checkpoint content.

## Boundaries

B4.6 does not repair, replace, or truncate metadata; change the ledger format; add a new persistence backend; add partial fills or expiry; expose mutation API routes; share portfolios; call providers; use live data; trade; deploy; commit; or push. The B4.1 contract remains the source of truth for broader persistence, backup, retention, and migration policy.

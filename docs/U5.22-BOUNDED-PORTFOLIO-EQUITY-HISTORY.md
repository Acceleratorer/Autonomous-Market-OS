# U5.22 Bounded Portfolio Equity History

**Status:** Implemented locally on 2026-10-29.

**Scope:** Expose a bounded view of the Python broker's retained paper-equity
history in the local Next.js portfolio detail page.

## Contract

- `GET /v3/b4/portfolios/{portfolio_id}/inspection` adds an `equity_history`
  object to the v2 inspection shape. V1 and v2 remain unchanged.
- The broker returns the latest 100 retained samples in event-time order.
  Timestamps may be equal because the broker records initial and post-event
  equity at the same event time. Each value remains an exact decimal string in
  USDT.
- Page metadata reports the number of returned and retained samples and
  whether older retained samples were omitted. Exact minimum and maximum values
  describe only the returned page. The new response is available only from the
  aggregate route, so broker recovery still happens once per request.
- The Next.js server validates the v3 identity, bounds, timestamps, decimal
  values, and ordering. It renders a static SVG for two or more samples and an
  exact-value table for every returned sample. A one-sample or empty history
  receives an explicit state.
- Plot coordinates use numeric conversion for display only. The broker owns
  equity and page extrema; the table preserves the exact returned values.
- The page remains a server-rendered GET consumer. No client state, new
  dependency, calculation of P/L or drawdown, mutation route, or animation is
  added.

## Design

The chart uses the existing dark, dense operator design system, a restrained
blue line, quiet grid lines, UTC range labels, and exact range extrema. The
table is the accessible precision fallback. Motion was excluded because this
frequently inspected financial view benefits from stable values rather than
decorative or scroll-triggered movement.

## Remaining limits and gates

- The chart shows only the latest returned 100 samples from the broker's
  policy-retained risk window; it is not lifetime portfolio performance.
- The line is a visual guide and the chart coordinates can lose decimal
  precision. Use the exact broker rows for precise inspection.
- U5.5 still gates connected access on target, identity, isolation, and
  operations decisions. The portfolio remains synthetic, paper-only, local,
  and read-only.
